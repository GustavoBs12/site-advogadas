# Ferreira & Lima Advocacia — Site Institucional

Site institucional desenvolvido para um escritório de advocacia fictício, criado como projeto de estudo aplicando **metodologia ágil** (Kanban + Sprints) do planejamento ao deploy.

🔗 **Site no ar:** [site-advogadas.vercel.app](https://site-advogadas.vercel.app/)

## 🎯 Sobre o projeto

O objetivo foi praticar todo o ciclo de desenvolvimento de um site institucional simples: da definição de requisitos (User Stories) até a publicação, passando por versionamento com Git, organização de tarefas em quadro Kanban, e boas práticas de HTML/CSS responsivo.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, Media Queries)
- Git & GitHub
- Vercel (deploy)

## 📋 Metodologia

O projeto foi dividido em sprints, com o progresso acompanhado em um quadro Kanban no GitHub Projects:

- **Sprint 0:** Levantamento de requisitos e criação do backlog
- **Sprint 1:** Estruturação do projeto e repositório
- **Sprint 2:** Cabeçalho e página inicial
- **Sprint 3:** Seções "Sobre" e "Áreas de Atuação"
- **Sprint 4:** Seção de Contato e rodapé
- **Sprint 5:** Responsividade para dispositivos móveis

## 📱 Funcionalidades

- Layout responsivo (desktop e mobile)
- Navegação por âncoras entre seções
- Botão de contato direto via WhatsApp
- Design com identidade visual consistente

## 🚀 Como rodar localmente

```bash
git clone https://github.com/GustavoBs12/site-advogadas.git
cd site-advogadas
```

Depois, é só abrir o `index.html` no navegador (ou usar a extensão Live Server do VS Code).
